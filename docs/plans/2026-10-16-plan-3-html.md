# rulebook — Plan 3: `rulebook build` and the HTML reference document

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `rulebook build` turns the Markdown cards into `rulebook/rulebook.html`. It is a single self-contained document that reads top to bottom:
- a versioned header;
- a "since last version" block;
- a table of contents;
- every domain → policy → rule, with plain-language evidence lines;
- a "To validate" section;
- a footer.

Search, filters and the theme toggle are progressive JavaScript on top of static markup.

**Architecture:** The HTML is **rendered statically in Node**, so it works without JavaScript, prints cleanly and can be tested as a string. A small inline script adds search, filters and the theme toggle.

| Module | Role |
|---|---|
| `src/parse/indexmd.js` | Reads the domain map |
| `src/build/data.js` | Builds one view model from cards, inbox and history |
| `src/build/i18n.js` | Labels in English and French |
| `src/build/render.js` | Produces the HTML string, inlining `viewer.css` and `viewer.js` |
| `rulebook build` | Writes the file and records publication dates in `rulebook/.published.json` |

**Tech Stack:** Node ≥ 20 ESM, zero dependencies, `node:test`.

**Spec:** `E:\Dev\rulebook\docs\specs\2026-10-15-rulebook-design.md` §7 (HTML document) and §4 (files). Plans 1 and 2 are merged in `main`.

## Global Constraints

Plan 1's constraints still hold, along with these:

**Self-contained output**
- The output has no external resources: no CDN, fonts, images or network calls.
- The only `http(s)` URLs in the file are evidence links built from `config.repoUrl`.

**Text rendering**
- All card text is HTML-escaped.
- The only markup interpreted inside card text is inline `` `code` ``.
- The embedded JSON escapes `<`, so `</script>` cannot break out.

**Fidelity**
- Text is copied verbatim from the cards and never reworded.
- UI labels follow `config.language` (`en`, `fr`). Any other value falls back to `en`.

**Evidence links**
- With `repoUrl`, links point to `<repoUrl>/blob/<commit>/<path>#L<start>-L<end>`. GitLab URLs use `/-/blob/`.
- Without `repoUrl`, links are relative (`../<path>`), because the document sits in `rulebook/`.

**Visual direction (validated in brainstorming)**
- Calm, editorial and text-first, with generous whitespace.
- The rule statement is set in a serif.
- One confidence indicator per rule, written in plain words.
- IDs and categories stay secondary.
- Status tags appear only for new, changed and retired rules.
- Light and dark themes, mobile-friendly, with a print stylesheet.

**Publication dates and the "since" block**
- `rulebook/.published.json` holds `{ "current": "YYYY-MM-DD", "previous": "YYYY-MM-DD" | null }`.
- A build on a new day shifts `current` into `previous`.
- The "since" block lists history entries dated after `previous`. `--since <date>` overrides it.

## Review Focus

1. **Card text containing HTML or `</script>`.** It must render as text, never as markup. *(Task 2)*
2. **A domain listed in `index.md` with no domain file yet.** It appears greyed out as "not extracted yet" and does not crash. *(Task 1)*
3. **No `repoUrl`, and a GitLab `repoUrl`.** Links must still work. *(Task 2)*
4. **Several builds on the same day.** The "since" baseline must not move. *(Task 3)*
5. **An empty rulebook (no cards).** The page still builds and says so. *(Task 3)*

```js
const LINE = /^-\s+\*\*([A-Z]{3})\*\*\s+[·—–-]\s+(.+?)(?:\s+[—–]\s+(.*?))?\s*$/;

export function parseIndexMd(text) {
  return text.replace(/\r\n?/g, '\n').split('\n').flatMap((line) => {
    const m = line.trim().match(LINE);
    return m ? [{ code: m[1], title: m[2], description: m[3] ?? '' }] : [];
  });
}
```

```js
const CHANGE_TYPE = { created: 'new', changed: 'changed', retired: 'retired' };

function sinceItems(cards, from) {
  if (!from) return [];
  const items = [];
  for (const card of cards) {
    for (const h of card.history) {
      if (h.date > from && CHANGE_TYPE[h.change]) {
        items.push({ type: CHANGE_TYPE[h.change], id: card.id, title: card.title, date: h.date, note: h.note });
      }
    }
  }
  return items.sort((a, b) => (a.date < b.date ? 1 : a.date > b.date ? -1 : 0));
}

function toValidate(cards, inboxText) {
  const out = [];
  for (const card of cards) {
    if (card.sections.openQuestions) out.push({ type: 'question', id: card.id, title: card.title, text: card.sections.openQuestions });
    if (card.meta.audit?.startsWith('failed')) out.push({ type: 'audit', id: card.id, title: card.title, text: card.meta.audit });
    if (card.meta.confidence === 'conflicting') out.push({ type: 'conflicting', id: card.id, title: card.title, text: card.sections.rule ?? card.title });
  }
  for (const line of (inboxText ?? '').replace(/\r\n?/g, '\n').split('\n')) {
    if (line.startsWith('- [ ] ')) out.push({ type: 'inbox', id: null, title: null, text: line.slice(6) });
  }
  return out;
}

export function buildData({ name, commit, today, version, config, domainsMap, domainFiles, inboxText, sinceFrom }) {
  const byCode = new Map();
  for (const entry of domainsMap) byCode.set(entry.code, { ...entry, file: null });
  for (const file of domainFiles) {
    if (!file.domain) continue;
    const known = byCode.get(file.domain.code);
    byCode.set(file.domain.code, {
      code: file.domain.code,
      title: known?.title ?? file.domain.title,
      description: file.domain.description || known?.description || '',
      file,
    });
  }

  const allCards = domainFiles.flatMap((f) => f.cards);
  const domains = [...byCode.values()].map((d) => {
    const cards = d.file?.cards ?? [];
    const policies = cards.filter((c) => c.kind === 'policy').map((card) => ({ card, rules: cards.filter((r) => r.kind === 'rule' && r.policy === card.id) }));
    return {
      code: d.code, title: d.title, description: d.description, extracted: Boolean(d.file),
      policies, otherRules: cards.filter((r) => r.kind === 'rule' && !r.policy),
    };
  });

  const rules = allCards.filter((c) => c.kind === 'rule');
  return {
    project: { name, commit, builtAt: today, version, language: config.language ?? 'en', repoUrl: config.repoUrl ?? null },
    since: { from: sinceFrom ?? null, items: sinceItems(allCards, sinceFrom) },
    counts: {
      domains: domains.length,
      extracted: domains.filter((d) => d.extracted).length,
      policies: allCards.filter((c) => c.kind === 'policy').length,
      rules: rules.length,
      edgeCases: rules.reduce((n, r) => n + r.edgeCases.length, 0),
    },
    domains,
    toValidate: toValidate(allCards, inboxText),
  };
}
```

```js
import { readFileSync } from 'node:fs';
import { t } from './i18n.js';

const asset = (name) => readFileSync(new URL(`./${name}`, import.meta.url), 'utf8');

export function escapeHtml(s) {
  return String(s ?? '').replace(/[&<>"']/g, (c) => ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;' })[c]);
}

export function inline(s) {
  return escapeHtml(s).replace(/`([^`]+)`/g, '<code>$1</code>');
}

export function evidenceHref(repoUrl, commit, ev) {
  if (!repoUrl) return `../${ev.path}`;
  const base = repoUrl.replace(/\/+$/, '');
  const blob = /gitlab/i.test(base) ? '/-/blob/' : '/blob/';
  const lines = ev.end > ev.start ? `#L${ev.start}-L${ev.end}` : `#L${ev.start}`;
  return `${base}${blob}${commit}/${ev.path}${lines}`;
}

function tagFor(card, since, L) {
  if (card.meta.status === 'retired') return { type: 'retired', date: null };
  const latest = since.items.find((i) => i.id === card.id);
  return latest ? { type: latest.type, date: latest.date } : null;
}

function renderRule(card, data, L) {
  const tag = tagFor(card, data.since, L);
  const conf = card.meta.confidence ?? 'inferred';
  const evidence = card.evidence.map((ev) => {
    const file = ev.path.split('/').pop();
    return `<a href="${escapeHtml(evidenceHref(data.project.repoUrl, data.project.commit, ev))}">${escapeHtml(`${file}:${ev.start}`)}</a>`;
  }).join(' · ');
  const search = [card.id, card.title, card.sections.rule, card.sections.context, ...card.edgeCases.map((e) => e.text)].join(' ').toLowerCase();
  return `<article class="rule${tag?.type === 'retired' ? ' is-retired' : ''}" id="${escapeHtml(card.id)}" data-kind="rule" data-category="${escapeHtml(card.meta.category ?? '')}" data-confidence="${escapeHtml(conf)}" data-status="${escapeHtml(card.meta.status)}" data-search="${escapeHtml(search)}">
  <div class="rule-head"><a class="rid" href="#${escapeHtml(card.id)}">${escapeHtml(card.id)}</a>${tag ? `<span class="tag tag-${tag.type}">${escapeHtml(L.tag[tag.type])}${tag.date ? ` ${L.on} ${escapeHtml(tag.date)}` : ''}</span>` : ''}</div>
  <h4 class="rule-title">${inline(card.title)}</h4>
  ${card.sections.rule ? `<p class="statement">${inline(card.sections.rule)}</p>` : ''}
  ${card.sections.context ? `<p class="context">${inline(card.sections.context)}</p>` : ''}
  ${card.sections.parameters ? `<p class="meta"><span class="label">${escapeHtml(L.parameters)}</span> ${inline(card.sections.parameters)}</p>` : ''}
  ${card.edgeCases.length ? `<div class="cases"><span class="label">${escapeHtml(L.edgeCases)}</span><ul>${card.edgeCases.map((e) => `<li id="${escapeHtml(e.id)}">${inline(e.text)}</li>`).join('')}</ul></div>` : ''}
  <p class="evidence"><span class="dot conf-${escapeHtml(conf)}" aria-hidden="true"></span>${escapeHtml(L.conf[conf] ?? conf)}${evidence ? ` · ${evidence}` : ''}</p>
  ${card.history.length ? `<details class="history"><summary>${escapeHtml(L.history)}</summary><ul>${card.history.map((h) => `<li>${escapeHtml(h.date)} · ${escapeHtml(h.change)}${h.note ? ` · ${inline(h.note)}` : ''}</li>`).join('')}</ul></details>` : ''}
  ${card.sections.openQuestions ? `<aside class="question"><strong>${escapeHtml(L.toValidate)}</strong> ${inline(card.sections.openQuestions)}</aside>` : ''}
</article>`;
}

function renderDomain(domain, index, data, L) {
  const n = index + 1;
  if (!domain.extracted) {
    return `<section class="domain is-empty" id="${escapeHtml(domain.code)}"><h2>${n}. ${inline(domain.title)}</h2><p class="lede">${inline(domain.description)}</p><p class="muted">${escapeHtml(L.notExtracted)}</p></section>`;
  }

  ${p.rules.map((r) => renderRule(r, data, L)).join('\n')}
</section>`).join('\n');
  const others = domain.otherRules.length
    ? `<section class="policy" data-kind="policy"><h3>${n}.${domain.policies.length + 1} ${escapeHtml(L.otherRules)}</h3>${domain.otherRules.map((r) => renderRule(r, data, L)).join('\n')}</section>`
```

```js
import fs from 'node:fs';
import path from 'node:path';
import { loadProject, domainFiles } from '../project.js';
import { headSha } from '../git.js';
import { parseDomainFile } from '../parse/cards.js';
import { parseIndexMd } from '../parse/indexmd.js';
import { buildData } from './data.js';
import { renderHtml } from './render.js';

const pad = (n) => String(n).padStart(2, '0');
export const localDate = (d) => `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}`;

export function nextPublished(published, today) {
  if (!published?.current) return { current: today, previous: null };
  if (published.current === today) return { current: today, previous: published.previous ?? null };
  return { current: today, previous: published.current };
}

const readText = (p) => (fs.existsSync(p) ? fs.readFileSync(p, 'utf8') : '');

export function runBuild(io, opts, version) {
  let project;
  try { project = loadProject(io.cwd, opts.dir); } catch (err) { io.stderr.write(`rulebook: ${err.message}\n`); return 1; }
  if (!project) { io.stderr.write(`rulebook: no ${opts.dir}/ folder in this git repository\n`); return 1; }

  const today = localDate(io.now ? io.now() : new Date());
  const publishedPath = path.join(project.dir, '.published.json');
  let published = null;
  try { published = JSON.parse(readText(publishedPath) || 'null'); } catch { published = null; }
  const next = nextPublished(published, today);
  const sinceFrom = opts.scope.kind === 'since' ? opts.scope.sha : next.previous;

  const files = domainFiles(project.dir).map((f) => parseDomainFile(readText(path.join(project.dir, f)), `${project.dirName}/${f}`));
  const data = buildData({
    name: path.basename(project.root),
    commit: headSha(project.root),
    today,
    version,
    config: project.config,
    domainsMap: parseIndexMd(readText(path.join(project.dir, 'index.md'))),
    domainFiles: files,
    inboxText: readText(path.join(project.dir, 'inbox.md')),
    sinceFrom,
  });

  const outRel = opts.out ?? `${project.dirName}/rulebook.html`;
  const outAbs = path.resolve(project.root, outRel);
  fs.mkdirSync(path.dirname(outAbs), { recursive: true });
  fs.writeFileSync(outAbs, renderHtml(data));
  fs.writeFileSync(publishedPath, `${JSON.stringify(next)}\n`);
  io.stdout.write(`rulebook: built ${outRel.replace(/\\/g, '/')} (${data.counts.rules} rules, ${data.counts.domains} domains)\n`);
  return 0;
}
```
